Axtify now runs as a desktop app with its own window, icon, and persistent local library.

- **Axtify-Setup-1.1.0-x64.exe**: Windows installer with Start menu and desktop shortcuts.
- **Axtify-Portable-1.1.0-x64.exe**: Windows app you can run without installing.
- **SHA256SUMS.txt**: download checksums.

Requires 64-bit Windows 10 or later. Node.js and a separate browser are not required. The portable app still stores library/settings in your Windows user profile; it does not carry your music on a USB drive.

Light crimson theme, editable appearance, local audio playback, playlists, likes, queue, and Spotify JSON playlist/track-list import are included. Spotify audio streaming is not included.

These builds are not code-signed. Windows may show an unknown-publisher warning. Desktop data is separate from your browser's library; reimport audio and Spotify JSON files if moving from the browser version.

MIT licensed. Source code and build workflow are public in this repository.
